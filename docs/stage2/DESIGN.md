# 2단계 — Design Space 도출 (구현 설계)

> 기준: 사용자 제공 `2단계_수정본.pptx`(슬라이드 1–12)와 그 가이드, `Formula1_본선발표`(PDF 판) 5·6·9·10·13쪽
> (Stage I → [이 후보로 개발 착수] → Stage II: QTPP → CQA → Risk 평가 → DoE toolkit → 공동확률 Design Space → 확인계획),
> Monton 2026(Scientifica 2026:3553253) Table 1·3–11, Almotairi 2022(Pharmaceuticals 15:1463) Table 3.

## 범위
- **1단계(후보 탐색)는 그대로 둔다.** 통과 후보 카드의 **[이 후보로 개발 착수]**가 2단계를 연다(1위 자동 진입 없음).
  조성·공정과 요청 맥락(대상 환자·용량·제형·약물 함량·1단계 신호)은 **불변 Handoff**(fingerprint)로 넘어가고, 2단계의 LLM 초안이 함께 읽는다.
- **입구 = 근거 결손 게이트**(발표 자료 ⑤, `formula/evidence/gate.py` · `evidence_requirements.csv` 16행 · 확인시험 마스터 66종). 통과 후보마다
  선행(before_protocol) 근거가 있는지 결정론으로 판정해 카드에 보이고, 결과(적합/부적합 · 값)를 넣으면 곧바로 재판정한다(`/api/runs/{id}/evidence`·`/confirmation`).
  선행 결손이 남았으면 연구자 사유(`evidence_waiver`)가 있어야 착수하고(없으면 409 `EVIDENCE_GAPS`), 부적합 결과가 있으면 착수 불가(409 `EVIDENCE_FAILED`).
  판정·남은 결손·사유는 Handoff에 들어가 지문에 포함되고, LLM 초안 맥락("근거 결손(확인 전)")과 최종 보고서에도 실린다. 반려 권한은 여전히 룰북에만 있다.
- **논문은 참고 자료이지 정답지가 아니다.** 위험 등급처럼 판단인 칸은 논문과 달라도 오답이 아니라 검토 지점(화면: "참고 · 논문의 판단")이고,
  회귀·ANOVA·공동확률처럼 계산인 값만 같은 원자료에서 같은 결과가 나오는지를 테스트로 고정한다.
- v6.1 개발 스튜디오와 v7 DoE 실험개발은 삭제했다. 2단계는 이 흐름 하나로 간다.
- 화면은 대화 하나(가운데 입력 에이전트 → 카드가 아래로 쌓임, 오른쪽 관측 칼럼). 모양은 지환닷컴 공용 흑백 디자인 그대로다.

## 원칙
- LLM 초안은 판정이 아니다. 단계마다 연구자가 고치고 승인해야 다음으로 간다. LLM 응답이 없으면 아무것도 채우지 않는다.
- 결정론 검사: 4·6의 근거는 (변수 × 확정 CQA) 모든 칸을 정확히 한 번씩 덮어야 하고, 5·7 행렬은 그 근거에서 코드가 만든다(따로 입력하지 않음 → 불일치가 생길 수 없다).
  6은 처방의 모든 부형제를 평가해야 하고, 공정 이름(direct_compression 등)을 공정 변수로 쓰면 막는다.
  약물 함량 < 5 %(RTE008)인데 혼합 공정 × 함량균일성이 High가 아니면 경고한다.
- 8의 DoE 변수 후보는 제형·공정 변수 중 **하나 이상의 CQA에 High**인 것(Medium만 있는 변수는 관리·모니터링 대상으로 따로 보인다). **고르는 단계가 아니다**(사용자 결정, 2026-09-28) —
  어떤 변수를 요인으로 실험할지는 9단계 표에서 연구자가 적는다. 8단계는 코드가 만든 정리라 확인만 하고, 위험평가 보고서는 8단계에 들어오면 바로 나온다.
- 10의 모형 제안은 Design-Expert식 적합 요약: 순차 F(p < 0.05)가 유의한 가장 높은 차수, 별칭(추정 불가) 제외, 없으면 예측 R² 최대.
  예측 R²가 수정 R²보다 0.2 넘게 낮으면(또는 음수면) **과적합 의심** — 차수를 낮추거나 사유를 적어야 승인된다.
- 12의 ANOVA는 선택 모형의 부분(Type III) 제곱합, 잔차 = 적합결여 + 순수오차(같은 설정의 반복 run).
- 13의 영역은 평균 반응면이 아니라 **미래 배치의 예측분포**(t, 척도 √(SE² + 잔차분산))로 반응별 통과확률을 곱한 공동확률 ≥ 0.90인 격자점이다.
  분모는 설계점 convex hull 안의 격자점(축마다 21점), 설정점은 hull 경계에서 0.1 coded 이상 떨어진 점 중 공동확률 최대. **영역이 비면 규격을 완화하지 않는다**(승인 불가).
- 14는 결과를 보기 전에 잠근다(시각 · 해시). 다시 열면 잠금이 풀리고 15는 “다시 확인 필요”가 된다. 참고 배치(예: 논문 최적)는 승격·무효화 근거가 아니다.
- 15는 필수 3점 × 규격 반응 모두 (규격 통과 · 예측구간 안)이어야 VERIFIED(내부 사전계획 통과 — 규제 승인 설계공간이 아니다). 모형 적합에 쓰지 않은 새 독립 배치여야 한다.
- 재현 기준(테스트 고정):
  - CBD(Monton 2026): 행렬 = Table 5·7 84칸, 회귀·ANOVA = Table 10·11. 논문 규격(경도 4–6 kgf · 붕해 ≤ 30 s · 마손도 ≤ 1 %)에서 평균 기준 47.9 %지만 공동확률 ≥ 0.90은 **0 %**(최대 0.883, 경도가 경계) → 13단계에서 멈춘다.
  - 로르녹시캄(Almotairi 2022 Table 3, 발표 자료 10쪽): 제안 모형 = 분산 2차 · 마손도 선형 · DE30 2차 · AV 2차(AV 과적합 flag), 규격(분산 ≤ 180 s · 마손도 ≤ 1 % · DE30 ≥ 75 %(가정) · AV ≤ 15)에서
    지지 7,501 / 9,261점, 평균 기준 **77.2 % → 공동확률 47.6 %**, 설정점 2.7 · 12.5분 · 6.8 %(P 0.991), 설정점 DE30 예측구간 71.9–92.8(12개 비교 Bonferroni).
