여기서는 시스템이 묻고, 연구자가 정합니다

  1. 후보 고정 — 고른 처방 하나(candidate_id@version)가 불변 Handoff가 됩니다.
  2. 연구자가 계약을 정한다 — CQA 규격, FMEA 처리 방향, 요인 범위는 시스템이 제안하고 연구자가 승인합니다.
  3. 숫자는 코드가 — 설계행렬·회귀·예측구간·영역은 결정론 엔진이 계산하고, 판정은 룰북 171개 규칙이 합니다.
  4. 확인배치로 끝난다 — 독립 배치 3개가 잠근 예측구간 안에 들어와야 VERIFIED입니다.
